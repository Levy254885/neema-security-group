# Neema Security Group

Professional corporate website for **Neema Security Group**.

**Tagline:** Vigilance. Integrity. Protection.

## Tech Stack

- Next.js 15 (App Router)
- TypeScript
- Tailwind CSS v4
- Framer Motion
- Lucide React
- Next.js Image optimization

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```

## Project Structure

```
src/
├── app/                  # App Router pages & metadata
├── components/
│   ├── sections/         # Page sections (Services, About, CTA, etc.)
│   ├── ui/               # Reusable UI (Button)
│   ├── Navbar.tsx
│   ├── Hero.tsx
│   └── Footer.tsx
└── lib/
    └── utils.ts
```

## Design Notes

- Deep navy (`#071A2B` / `#04111D`) + gold (`#C99A3A`) accent palette
- Cinematic hero with restrained Framer Motion sequence
- Angular / editorial layouts inspired by professional security branding
- Fully responsive (mobile, tablet, desktop)
- SEO ready (metadata, robots, sitemap)
