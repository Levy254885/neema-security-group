# Neema Security Group

Professional corporate website for **Neema Security Group**.

**Tagline:** Vigilance. Integrity. Protection.

## Design

The site follows a premium corporate security UI pattern inspired by leading industry sites (editorial photography, clear hierarchy, functional carousel, strong CTAs). Brand colour is forest green (`#1B6B4A`).

## Tech Stack

- Next.js 15 (App Router)
- TypeScript
- Tailwind CSS v4
- Framer Motion
- Lucide React
- Next.js Image (Unsplash remote patterns)

## Pages

- `/` — Homepage (hero slider, services, resources, risks, who we are, news, careers, values)
- `/about` — Company overview & values
- `/services` — All services
- `/services/[slug]` — Individual service detail
- `/contact` — Quote / assessment request form

## Services

1. Manned Guarding
2. Corporate Security
3. Residential Security
4. Event Security
5. Access Control
6. Security Consulting

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```

## Notes

- All CTAs and arrows link to real routes.
- Hero carousel is fully functional (arrows, indicators, auto-advance).
- Mobile-first layout with intentional breakpoints.
- No fake statistics, certifications or testimonials.
